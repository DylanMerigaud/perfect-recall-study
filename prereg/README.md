# prereg

The preregistration written before any new reading is taken: the research questions, the
preregistered hypotheses with their pre-declared criteria, the validation protocols and
baselines compared, the census population rule and codebook, and the statistics plan. Tagged in
git (`prereg-v1`) so every later reading's timestamp can be checked against the tag's commit time.

Empty until the preregistration is written. See the root README for how this folder fits the
rest of the study.
