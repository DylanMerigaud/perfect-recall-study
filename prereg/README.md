# prereg

The preregistration written before any new reading is taken: the research questions, the
preregistered hypotheses with their pre-declared criteria, the validation protocols and
baselines compared, the census population rule and codebook, and the statistics plan. Tagged in
git (`prereg-v1`) so every later reading's timestamp can be checked against the tag's commit time.

- `PREREG.md`: the preregistration itself, with the arm sizes and their arithmetic, the
  thresholds used as shipped, and a dated amendments section at the end.
- `coverage-audit.csv`: the generator-coverage audit, one row per (physical process of real
  capture, check), written from code reading before any new reading; H6 scores it.

See the root README for how this folder fits the rest of the study.
