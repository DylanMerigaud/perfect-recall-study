# experiments

Code that produces each experimental arm: additional fictional identities and defect instances
for the base generator, a jittered variant of the same generator, a run of an independent
third-party generator on the rendered pages, a targeted foreign-ink run with its raw rows kept,
and the scripts that build, print and ingest a real-paper capture kit.

Raw readings these scripts produce are large and are not committed to this repository; they ship
through the Zenodo record once collection is complete.

Empty until the code lands. See the root README for how this folder fits the rest of the study.
