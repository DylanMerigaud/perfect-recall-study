# results

Tables, figures and the numbers registry (`numbers.json`) that the analysis scripts write. Every
number the manuscript quotes is read from a file in this folder, never typed by hand.

`naf.json` is the X3 result (T15); `naf-reading.md` is its reading, which marks the pixel measure invalid and P-NAF "not interpretable". See the root README for how this folder fits the rest of the study.
